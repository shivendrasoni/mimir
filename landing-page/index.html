CONTROL IS AN ARCHITECTURE

A serious runtime beneath the control plane.

Mimir is written in safe Rust for long-running, inspectable work. Policy remains in deterministic code beneath the model, where it can be tested and enforced.

Durable delegation

Bounded child agents remain scoped to their parent session and operational budgets.

Provider independence

Multiple model providers run through one typed runtime and one policy boundary.

Private evidence

Diagnostics exclude prompt text, model output, tool payloads, credentials, and absolute paths.

Bounded by design

Turns, tools, context, output, time, child concurrency, and provider retries remain controlled.

No Node.js runtime required. No unsafe Rust. No prompt masquerading as policy.
